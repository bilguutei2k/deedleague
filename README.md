# Deed League Index

Deed League Index is a read-only analytics site for Mongolia's Ündesnii Deed League, using msports GraphQL as the single data source.

## Structure

- `apps/web` - Next.js App Router frontend.
- `packages/db` - Drizzle configuration and database client plumbing.
- `pipeline` - Python CLI and msports client skeleton.
- `.github/workflows` - Workflow templates for refresh and deploy jobs.
